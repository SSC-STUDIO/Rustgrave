## 1. 阶段与验收

### 阶段二：样板规范推广到第 2–10 章
- 每章一套远景色阶（复用 `rust_grade` 参数化）+ 一种玩法变化的确认；悬浮平台与背景的明度分离规则写进美术规范。
- 奖励审查：第一章三枚重复窑核改为有意义的奖励（世界信息碑文 / 毒素上限 / 捷径），全章同查。
- 死亡回档策略：锈核等能力拾取即落盘（仅 consumed + 背包，不移动重生点），配迁移测试。
- 验收：每章入口/机关/Boss 截图；`-Campaign` 真实输入通关通过。
