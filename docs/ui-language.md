# Rustgrave UI 语言：板、铁架与弹窗

这份文档记录标题屏 / 暂停菜单 / 设置 / 操作说明 / 教程回看 / 地图这几块界面
共用的视觉规则。原则只有一句：**不换素材、不换风格，只换形状、层级和版式**——
所有形状都用现有 UI 贴图的调色板在运行时画，主题 `assets/ui/theme_rust.tres`
与 `assets/ui/*.png` 一张没动。

## 1. 三层动作

菜单行分三档，玩家在任何界面看到同一个信号就知道这行有多重：

| 档位 | 形状 | 用在 |
|---|---|---|
| 主行动 | 右端收成**箭头**的切角板（440×60） | 点燃余烬、回到锈墓、炉心复燃、送剑 |
| 次行动 | 右端剪出**燕尾**缺口（320×52） | 设置、地图、教程回看、操作说明、取消 |
| 第三层 | 只剩**四只 L 形角标**（280×52） | 离开锈墓、返回标题、熄灭、守火 |

- 选中 = 整块板换成金色四环（与 `btn_hover.png` 同色阶）+ 光标 + 火盆余烬 + 呼吸亮度。
- 禁用 = 暗铁四环 + 灰字。
- 形状由 `scripts/ui/menu_plate.gd` 现画：颜色与"四道环 + 抖动内芯"的结构照抄
  `tools/gen_ui_kit.py` 的 `buttons()`，所以板子只是"同一套素材换轮廓"，不新增贴图。
- `style_box()` 把整块板包成 9-slice，给需要任意宽度的 Button（设置页标签页、
  页脚按钮）当底，中段平铺、抖动内芯按 1:1 重复。

## 2. 铁架版式（标题屏 / 暂停菜单）

行列表不是浮在空中的：左侧一根**竖脊**（`ui_ornament.gd` 的 `spine()`），每行向左
伸一根**挂钉**（`MenuItem` 的 `_draw`），选中时挂钉烧成余烬色。
标题屏用"上字标 + 左下铁架 + 右下墓志"，暂停菜单用"左铁架 + 右行程档案"。

## 3. 弹窗外壳（`scripts/ui/ui_modal.gd`）

设置、操作说明、教程回看、地图、暂停菜单都是**从底下那层弹出来的卡片**，
而不是整屏铺一张紫板：

- 背景纱幕默认 `alpha 0.55`：只压暗到还看得见标题屏 keyart / 战场，
  四周再飘少量余烬；卡片后面那层永远留着。
- 内容卡是主题的花边面板，尺寸有上限、居中悬浮；设置 900×640、暂停 1020×640、
  操作说明 900×620、教程回看 880×580、地图 1120×640。
- 卡片内部固定三段：**标题带**（kicker + HeadLabel + 铆钉横线）、**内容区**、
  **底部锈色提示带**（左提示 / 右 Esc 文案）。
- 开屏只让纱幕从亮淡到暗（0.12s），卡片本身立刻到位：卡片跟着淡入会在开头
  0.1s 变成半透明，叠在暂停菜单上就是双重曝光。

## 4. 分组与可读性

- 设置页标签用同一套 TAG 板（未选暗铁、选中金框），页内内容垂直居中，
  每页底部补两句 12px 脚注解释"这页在改什么"。
- 操作说明按 移动 / 战斗 / 交互·剑核 / 系统 四段分块，每段 12px 小字标题 +
  锈色发丝线；内容超高时滚动（滚动条也换成槽/余烬填充贴图）。
- 12px 只给"说明/提示"，24px 给正文，36px 给界面标题；像素字体只允许整数倍
  字号，焦点变化走颜色和 2px 栅格内的位移，不做几何缩放。

## 5. 尺寸与节奏

- 全部落在 2px 栅格上；按钮行高 52（触控下限 `UiKit.TOUCH_MIN`），主行动板 60。
- 行之间 6px；同一组内 10/14px；跨组 18/20px；卡片四周留 40px 设计像素。
- 选中反馈统一为"金色四环 + 光标 + 余烬"，任何界面都不另造一套选中语言。

## 6. 覆盖的界面

| 界面 | 外壳 | 版式 |
|---|---|---|
| 标题屏 | 无（keyart 全屏） | 上字标 + 左下铁架 + 右下墓志 |
| 覆盖存档确认 | 花边小卡 | 燕尾"取消" + 角标"确认覆盖" |
| 暂停菜单 | 弹窗卡 1020×640 | 左铁架 + 右行程档案（章节/目标/锈核/余烬巢/视口） |
| 设置 | 弹窗卡 900×640 | 标签页 + 页面 + 脚注 + 页脚按钮 |
| 操作说明 | 弹窗卡 900×620 | 四段键位表，可滚动 |
| 教程回看 | 弹窗卡 880×580 | 可滚动列表 |
| 地图 | 弹窗卡 1120×640 | 关卡横带 + 图例 |
| 炉心结局 / 终局选择 | 花边小卡 | 燕尾主项 + 角标第三层 |

## 7. 离开锈墓的退场

"离开锈墓"不是直接 `quit()`：整块标题屏会先熄灭，再压黑，最后留一句墓志才退出。

- 时间轴（总长约 2.1s）：菜单架自"点燃余烬"往下一格格淡出（每格错开 0.055s）→
  字标 / 副题 / 墓志 / 署名带 / keyart / 余烬一起暗下去 → 铁门落下的闷响（`gate`，
  与进关同一个音）→ 黑幕 0.85s 压上来 → 黑底上浮出"余 烬 熄 灭。"。
- 退场期间音乐 duck -10dB；`TitleScreen._process` 让出呼吸动画，交给淡出 tween。
- **任何按键 / 鼠标点击 / 手柄键都能立刻跳到退出**：退出游戏不该被动画拖住。
- 测试开关 `TitleScreen.quit_on_finish`（默认 true）：headless 套件置 false 走完整段
  动画但不结束进程；`is_quitting()` / `quit_finished()` 供断言。
