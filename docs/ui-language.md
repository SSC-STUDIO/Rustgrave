# Rustgrave UI 语言：刻字、吊灯与实物界面

标题屏和六个二级界面共用炉厅的材质、光与动作。菜单像刻在场景上的字，暂停时放下铁牌，设置时摊开账簿。新增纸、皮、铁、黄铜和封蜡由 `scripts/ui/ui_object.gd` 在运行时绘制并缓存；不新增 PNG，不替换 `assets/ui/theme_rust.tres` 和已有 UI 贴图。

## 1. 材质与层级

- 铁：暗铁底、锈色削角、冲压槽、短划痕和铆钉。深色表面用暖白刻字，选中时被吊灯照暖。
- 纸：不透明的泛黄纸页、暗墨字、纸边磨损和钉孔。纸张内容不会透出下层菜单文字。
- 皮：深褐封面、角板和中缝阴影，书页上方伸出书签布条。
- 黄铜与封蜡：用于可操作的小部件、书扣和确认动作，亮色面积保持克制。
- 主次行动继续由 `MenuItem.Kind` 表达，具体表面决定外观：铁上用灯标，书上用墨字；未迁移的界面仍可用箭头板、燕尾板和角标板。

## 2. 标题屏：字刻在炉厅里

`MenuList.lamp_style` 不画铁条和竖脊；左下七行刻字留出中间的骑士与铁桥。`MenuShade` 是羽化的烟雾暗斑，只压暗菜单附近的复杂管线。禁用行仍能读到名字，解锁条件挂在该行下方的 `LockTag` 小铁签上（6px 短链、10px 字），不挤在文字右端。

`TitleLampCursor` 用已有 12×17 灯笼帧按 3 倍显示，即 36×51 设计像素。灯芯随选中行用弹簧落位，暖光按距离衰减；选中行最暖，邻行留少量余温。字形不跟随灯笼旋转或缩放。

远处 `FarVault` 的冷蓝灰剪影、高窗光柱和 `FarHaze` 的熔河暖反光拉开纵深，复用现有光源预算。开屏用视差层做推镜，字标在镜头落位时锻入；`skip_intro()` 立即清掉推镜偏移并恢复终态。完整时间轴和图层顺序见 [title-live-scene.md](./title-live-scene.md)。

`FooterShade` 从 y=648 向下渐暗，为 y=688 的一行致谢与当前菜单提示留出暗底；页脚不另加边框大面板。

## 3. 六件实物

下面的尺寸是各消费者传入 `Modal.build` 的设计尺寸。布局和显示适配仍由容器及 `PresentationMetrics` 负责。

| 界面 | 实物与设计尺寸 | 内容与选择反馈 | 进退场 |
|---|---|---|---|
| 暂停菜单 | 吊挂铁牌，1020×640 | 左侧刻字菜单与吊灯，右侧钉住的行程签 | 双链放下，轻微回弹；退场收回 |
| 设置 | 锻炉账簿，960×560 | 四根书签页签；墨线滑条、黄铜珠、开关印章、铅字键位 | 从下方滑上，封面分帧打开；退场滑回 |
| 地图 | 蚀刻铁板，1120×640 | 顶部章节冲孔烧亮；左侧关卡剖面，右角章节纸签 | 铁板落位，四角钉子依次固定并闪火星 |
| 操作说明 | 四张旧纸的透明载体，1120×620 | 移动／战斗／交互·剑核／系统各一张独立纸；24px 动作说明和铅字键帽，兼顾小窗口 | 四纸每张错开 0.06 秒落位；整组退场 |
| 教程回看 | 随身手札，880×580 | 左页墨写目录，右页课文和正文涉及的键帽；两列留出书脊 | 滑上并翻开；关闭后回到原菜单 |
| 覆盖存档确认 | 封蜡信笺，640×420 | 默认选择取消；确认覆盖时红蜡短暂白热 | 信笺落下；取消收回，确认后转入角色选择 |

材质纹理网格为 2px；字体与实物本体保持 1:1 几何比例。过渡使用透明度和取整位移，封面用离散形状切换，不把像素文字缩放或旋转。模态背景复用屏幕拷贝和轻微模糊，再压暗并加暗角；纱幕 alpha 小于 0.8，周围仍能看见炉厅或暂停的战场。

## 4. 可操作的小部件

- **灯标行**：标题与暂停共用 `TitleLampCursor` 和 `MenuItem.lamp`，不在每行背后叠金框。
- **墨水行**：`MenuList.ink_style` 写入 `MenuItem.ink`，深墨文字、行首余烬点和淡墨下划线表达当前选择。
- **书签**：设置页 `Tab0..Tab3` 保留 `Button`；选中的布条更长、更亮，颜色分别为暗红、琥珀、冷铁和旧青。
- **滑条**：`HSlider` 保留拖动和键盘行为，轨道换墨线与 10% 刻度，滑块用黄铜珠。
- **印章**：开／关状态用实印和空印区分，仍由原来的按钮切换设置值。
- **铅字键帽**：操作说明和手札使用纸面上的暗边小框，键名从 `KeyLabels` 读取；重新绑定后同步更新。
- **章节冲孔**：`MapScreen.RouteRail` 保留点击与左右选章，孔内亮度表示已抵达／所在章；纸签随选章同步。

## 5. 模态接口与生命周期

`Modal.build(host, opts)` 的 `object` 参数选择 `ObjectKit.Kind.BOARD / LEDGER / PLATE / NOTES / JOURNAL / LETTER`。不传 `object` 的消费者继续使用原有花边／玻璃外壳。

节点路径保持 `ModalRoot/Card/Content/Body/...`，返回字典的 `root / veil / card / body / footer / hint / back / field` 和 `play_intro / play_outro / finish_instantly` 入口保持不变。实物 `Card` 通过 `object_kind` 元数据记录材质，附件在 `ModalRoot/Dressing`，不占正文布局。

关闭在退场回调后隐藏并发出 `closed`。重新打开时取消上一条过渡并恢复位置，避免旧回调把新打开的窗口隐藏。无头测试直接落终态；真正的动效和材质仍要看有渲染目标的截图。暂停下打开子界面不创建重复实例，不提前解除暂停；关闭子界面后把输入交回暂停菜单。

设置的 `slider_for() / tab_button() / toggle_for() / key_button_for()` 继续返回 `HSlider / Button`；标题的 `ConfirmMenu`、菜单项 id 和取消默认项保持。修改外观不提前清除存档：确认覆盖仍先进入角色选择，真正启程沿用原来的新游戏流程。

## 6. 未迁移控件与旧版板形

HUD、角色选择、装备、试炼、故事／日志和回看余烬不属于这批六件实物的迁移范围；保留各自现有外壳及 `menu_plate.gd` / `GlassKit` 组件。

`menu_plate.gd` 的主行动箭头板（440×60）、次行动燕尾板（320×52）与第三层角标板（280×52）继续供这些界面使用。它们的金框反馈属于板形控件，不应套回标题刻字、账簿目录和纸张正文。按钮触控行高保持 `UiKit.TOUCH_MIN`；说明与小题头可用 12px，正文和标题使用现有主题字号。

`GlassKit.kicker / spacer / rule / diamond / SealMark / ChapterRail / done_from_flags` 保留供旧屏和共享装饰使用。纸面上借用 `kicker` 时清除它的余烬色 `modulate`，再设置墨色，避免多次染色导致字太暗。

## 7. 离开锈墓

离开标题时仍逐行熄灭菜单、压暗炉厅并在黑幕上留下「余 烬 熄 灭。」；任何按键、鼠标点击或手柄按钮都可跳到退出。`quit_on_finish` 测试开关和 `is_quitting() / quit_finished()` 接口保留。
