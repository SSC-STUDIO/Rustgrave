# 标题屏 · 炉火回应（第三轮微改进）

在 v3 活景标题 + 灯标版式之上做的一轮**交互与温度**打磨： idle 画面基本不变，
 gains 全在「玩家动手 / 回来」的那一刻。不改主题、不新增运行时贴图、不新增光源。

## 1. 驻足读碑（墓志可交互）

底部墓志原来只是自动轮换的打字机，玩家没法停下来读、也没法换一句。现在：

- **悬停 = 驻足**：鼠标停在墓志条上，停留计时冻结、字色从 `EPITAPH_PEAK=0.58`
  提到 `EPITAPH_READ=0.92`，正在淡出的句子会被拉回停留整句亮着；页脚换成
  「墓志 · 悬停驻足 · 点击换一句」。移开即恢复轮换与菜单提示。
- **点击 = 换句**：整条墓志盖了一层透明 `EpitaphTap` 按钮（`StyleBoxEmpty` 全样式盒，
  不抢键盘焦点 `FOCUS_NONE`），点一下立刻换下一句、从第一个字重新敲，伴 `ui_tick`。
- **笔尖余热 `EpitaphPen`**：纯 `_draw` 整数像素（6px 拖尾 + 3px 热芯 + 1px 白火星），
  跟着已敲出的字宽停在右对齐行的写字头；敲完进入停留就凉下去。不是灯，UI 点光预算仍为 0。

弹窗盖上来 / 退场 / 已开局时不收悬停；`_process` 里发现模态打开会主动解除驻足。

## 2. 炉厅识客（欢迎回来）

`EmberSigils` 本来就记着每次点燃。播完开屏（`_finish_intro`，**不含**跳过开屏）后，
若印记里有旧记录，页脚先道一声欢迎，`WELCOME_HOLD=5s` 后让位给菜单提示：

- 今天来过：`欢迎回来 · 炉火还温着`
- 昨天来过：`欢迎回来 · 昨日余烬未冷`
- 更久：`欢迎回来 · 上次点燃在 N 天前 / N 个月前`（走 `EmberSigils.ago_text`）

焦点一动（`_refresh_footer_hint`）欢迎语立刻让位；冷启动（无印记）不招呼。

## 3. 字标余烬（shader 呼吸）

`title_forge.gdshader` 锻入收尾后，字标底部沿 UV.x 爬过一道**量化**的余烬暖光
（`smoothstep(0.62,0.98,UV.y)` 锁在字根，`floor(crawl*3)/3` 保持像素感，幅度 0.12），
像铁字底下压着的煤。 gated on `progress≈1`，锻入过程不受影响；无新 uniform、无新灯。
