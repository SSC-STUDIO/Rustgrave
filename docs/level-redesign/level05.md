## 机关、支路与持久化

- 传送带：两段使用 ConveyorBelt，速度 ≤36px/s，第二段每 5.2 秒反向且先停 0.6 秒。带区不放喷口，不在带上放巢、碑、压板或奖励。
- 蒸汽：CyclicHazard 的 steam，最少 0.8 秒预警；全部位于静态台面；从传送带结束处到最近喷口至少一段安全站台。首遇安全区无敌人射程覆盖。
- 五台旧名吊台承担真实换层 / 接力：D 从地面到 112；C 在 224 横送；F 从 224 到 112；E1/E2 相差半周。吊台全行程不得穿过实体。
- 钩锁可选支路：SteleNook 的检修龛移到 96px，和顶轨横向分离；HoistDeck 移到 128px，钩锁上去穿过独立蒸汽挑战得到 iron_carapace。两条支路都要求 `allow_hook=false` 不可达、true 可达。
- 保留 Props 的 EmberNestStart / Lift / Gate / Hoist、GateAPlate / Door、GateBPlate / Door、RustGate、三块旧碑，以及 Pickups/TetherCoreE、RewardHoist，保持存档 v2 与故事注册表。四巢 x=176 / 1168 / 2160 / 3152，相隔 992px。
- 原四口冷却液坑不再作为通路模板；用带区、静态蒸汽廊、地面/中层/顶轨切换重写路径。仍以真实玩家检查低处通路的头部净空和吊台上下船，不保留有困路风险的薄缝。
