# 余烬竞技场：3D 版本

2026-10-31 按用户决定，竞技场采用远端 `cursor/moba-3d-render-spike-4fbe` 的 3D 像素版本，来源提交 `b54acec96e832d295c4f22cef7ce09d31516aa73`。旧 2.5D 大厅与对局已撤下玩家入口，不迁移其玩法到新版本。

## 入口与返回

标题菜单的「余烬竞技场」以及「回看余烬」中的同名入口都进入 `scenes/moba/RenderSpike.tscn`。原 `ArenaRun.start()` 作为兼容调用转发到 `scripts/moba/moba_run.gd`，不再启动旧大厅、倒计时、计分或 2D HUD。

3D 场景直接加载，拥有独立 `SubViewport / World3D / Camera3D`，不经过关闭 3D 渲染的 `GamePresentation`。

Esc、手柄返回动作以及屏幕「返回标题」按钮共用退出流程；连续返回只发出一次切场请求。离场期间停止操控，场景退出后解除会话锁。

## 当前内容

- 正交俯视的 3D 炉城中路：熔岩河与桥、蓝红双方塔和水晶、墙、草丛与岩石。
- 可操控余烬骑士，移动、过顶挥剑和触屏操作；双方循环兵线。
- 原分支的低分辨率整数放大、纹素吸附、色阶光照、外壳描边和步进动画。
- 普通入口显示简短操作提示；F3 可展开开发统计与画面验证选项。

**已完成第一条可玩闭环（2026-10-31，P1 + P3 的最小切片）。** 现在是一场**单路 1v1 对局**：

- 双方各 1 座塔（HP 1200，先打小兵再打英雄）与 1 个水晶（HP 2400）；每 20s 双方各出 3 个小兵沿路推进、遇敌互殴；首波 5s。
- 玩家操控余烬骑士（HP 600，攻击 55/0.6s，射程 2.2m，移速 4.5m/s，死亡 6s 后基地复活），红方由**确定性 AI 英雄**推进对线。
- 任意水晶被摧毁即结算：HUD 顶部双方水晶血条、波次倒计时、英雄血条/复活倒计时，结算条显示「灰卫攻破锈誓水晶 / 锈誓攻破灰卫水晶」，`R` 重开、`Esc` 返回。
- 模拟核心 `scripts/moba/sim/moba_sim.gd` 是 30Hz 固定步进的**确定性**模拟（整数毫米、种子 RNG、逐 tick `state_hash()`），表现层只读状态不结算伤害；测试 `tests/moba_sim_*_test.gd` + `tests/moba_view_*_test.gd` 共 66 例。
- 实测：会用命令的玩家约 **54.6s** 可拆掉红水晶获胜；完全挂机约 **62.1s** 被红方 AI 推平。胜负窗口还偏窄，后续 P3/P5 调 AI 与技能会拉开。
- 仍未做：英雄技能/大招（P3 后续）、经济/商店/装备（P4）、5v5 三路与野区（P5）、完整 HUD/小地图/触屏技能盘（P6）、正式美术与音效（P7）。标题档案显示「3D场景试演」，不会沿用旧 2.5D 胜场冒充新模式成绩。

## 操作

左右移动沿用设置中的移动按键；W/S、方向键与手柄纵轴控制远近方向。挥剑沿用攻击动作，也可使用跳跃动作（默认空格），画面提示会显示当前绑定；触屏按住移动、双击挥剑。滚轮或 +/- 调整视野，Esc／返回键／屏幕按钮返回标题。相机震动遵守设置中的震屏强度。

开发统计默认隐藏；F3 或启动参数 `--debug` 展开原分支的 0–9、M、P 画面验证按键；展开后 H 可显示／隐藏调试帮助。原 `--shot-after` 和 `--quit-after-shot` 仍供自动截图使用。

## 战役与兼容边界

新会话不启动旧 `ArenaRun.active()` 状态。战役中既有的竞技场兼容引用保留，避免牵动玩家、伤害和存档的战役行为；旧模式源码与规则仅作为历史实现，不提供玩家入口，原规范归档于 [2.5D 历史记录](archive/arena-2_5d-mode.md)。

`ArenaRun.blocks_campaign_save()` 包含新 3D 会话状态，因此现有 SaveData 的写盘、读档、删档与档案保护继续生效。3D 会话不改 `GameContext.pending_world_path`、战役进度或旧竞技场记录；保持战役时钟冻结，退出还原原有时钟持有状态。
