# 标题屏细节与质感打磨（第二轮）

在 v3 活景标题（`TitleWorld` + `TitleScreen`）基础上做的一轮细节打磨，不改主题、不新增运行时贴图。

> 灯标这一轮改掉了下面几处当时的做法：标题菜单不再是铁条，光标是 `TitleLampCursor`；
> 右侧长列和四枚芯片收成一条淡短注（横向 14 格）；活景不再加四角角标，暗角改成软渐变；
> 墓志去掉底板、顶线和钉子，只留炉影里的一块暗斑。下面第 2–5 节是当时的记录，以
> [`title-live-scene.md`](./title-live-scene.md) 的现行描述为准。

## 1. 修掉一处真实重叠

- **回看余烬条 vs 墓志句**：两者都位于右下（按钮 x=1000..1208 / y=617..645，墓志 y=624..656 且右对齐到 1208），
  墓志打满整句时中段会被按钮盖住。
- 修复：墓志区 `EPITAPH_RECT` 从 `(688,624,520,32)` 收到 `(600,624,384,32)`，
  右端停在 x=984，和旅程列（x=1000）留 16px；打字机、轮换、`_fit_epitaph()` 不变。
- 新增测试 `test_epitaph_clears_recap_button()`：墓志右端与回看条左端至少留 8px。
- 用矩形诊断脚本扫过全部标题 UI（菜单 7 格、旅程列 10 个元素、墓志/页脚/更新提示/档案卡），
  当前 **OVERLAPS = 0**。

## 2. 旅程列版式与质感

- 标题「旅程」下加一道 1px 锈线，列左侧加一根 1px 导引线，和菜单架脊/芯片左侧条同一语汇。
- 四枚芯片（阶 / 装 / 试 / 竞）加 1px 内分隔线，值列左移 4px、右侧留 6px，四枚读起来像同一套仪表；
  「胜 0 场」补空格（原先「胜0场」挤成一块）。
- 刻度尺：每一幕名左侧加小 L 形导轨，并**高亮当前幕**（余烬色），其余幕保持骨白 55%；
  第一章「醒」在存档进度下会烧亮，和当前章菱形呼应。
- 「回 看 余 烬」从默认主题大按钮改为和芯片同宽的静谧次行动条：extras 主题 + 12px 字号 + 左侧余烬条，
  不再和「继续旅程」抢视觉重心；去掉字体里没有的箭头字符，避免豆腐块。

## 3. 其他微调

- 菜单未解锁注记（"第七章后解锁"）压到 10px、80% 不透明度，留在行尾但不抢行题。
- 活景模式补四角 12px 角标框，和上下暗角一起把画面收住；旧静态 keyart 分支原本就有。
- 继续保留：章节 `TitleGauge` 当前章脉冲、悬停旅程列展开档案卡、菜单悬停世界反应（`TitleWorld.react_to`）、
  开屏锻字/逐条落位/墓志打字机。

## 4. 验证

- `title_screen` 24/24、`title_world` 20/20、`title_flow` 6/6、`m5_tier5` 13/13、`modal_screens` 5/5。
- 截图：`screenshots/peek/title-polish/title_final.png`（全屏）、`title_journey_detail.png`（旅程列细节）。


## 5. 第三轮：动效与档案卡细节

- **墓志 / 回看条重叠**：`EPITAPH_RECT` 再收窄到 `(600,624,384,32)`，右端 984，与旅程列 `x=1000` 留 16px；
  新增 `test_epitaph_clears_recap_button()`（至少 8px 间距）。矩形诊断 OVERLAPS = 0。
- **墓志换行节奏**：新句先 0.22s 淡入，再按 `EPITAPH_CHAR` 打字；旧句用 smoothstep 淡出，不再硬切。
- **旅程列**：标题下加 1px 锈线、列左加 1px 导引线；芯片加 1px 内分隔并给值列留白；
  刻度尺每一幕加小 L 导轨，当前幕名烧成余烬色。
- **回看余烬**：从默认大按钮改为同宽暗色次行动条，左侧余烬条 + ASCII `>` 箭头；去掉字体不支持的 `›`。
- **档案卡**：`TitleCard` 补右下 4/5px 落影；顶部余烬饰条加厚并加中央亮点；
  内容拆成「成长 / 旅程」两个小节（小字 + 渐隐锈线），行距 10→12，下半空白明显收紧。
- **四角**：活景模式补 12px 角标框，和暗角共同收住画面。
- **菜单注记**：未解锁提示 10px / 80% 不透明度。

验证：`title_screen` 24/24、`title_world` 20/20、`title_flow` 6/6、`m5_tier5` 13/13、`modal_screens` 5/5。
截图：`screenshots/peek/title-polish/title_polish3.png`、`title_card.png`、`title_journey_detail.png`。
