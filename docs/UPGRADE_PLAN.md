# Rustgrave 全面升级计划

## 当前状态分析（2026-10-17）

### 已完成的核心系统
- ✅ 十章关卡布局（level01-10）
- ✅ 近战与弹反系统（melee_combat.gd）
- ✅ 毒素燃料机制
- ✅ 剑核组合系统
- ✅ 钩锁移动
- ✅ 存档/读档（SaveData）
- ✅ Boss 战斗
- ✅ 键鼠与触屏操作
- ✅ 开场分镜系统（opening_cinematic.gd）
- ✅ 章节过场（Director + CinematicPresentation）

### 主要问题识别
1. **视觉一致性**：素材风格、尺寸、接地、光照不统一
2. **动作手感**：输入响应有迟滞，连招窗口不清晰
3. **关卡引导**：缺乏视觉引导，依赖文字提示
4. **演出完整性**：Boss登场、能力获得缺少仪式感
5. **音频层次**：环境声、脚步声覆盖不完整
6. **界面一致性**：UI 风格未完全统一

## 升级策略：样板驱动 + 逐章推广

**目标**：打造"标题→开场→第一章→核心战斗→Boss→下一章"的完整流程样板

#### 1.2 第一章视觉升级（1天）

## 执行原则
1. **先做后说**：每个阶段直接实施，不停在计划
2. **持续验证**：改一处，测一处，提交一次
3. **保留成果**：不重复造已有系统
4. **分批提交**：功能清晰的改动立即提交
5. **视觉验收**：实际运行游戏检查画面效果
