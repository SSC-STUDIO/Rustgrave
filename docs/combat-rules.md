# 战斗规则（combat-rules）

本页的数字全部来自 `scripts/combat/combat_rules.gd`（`CombatRules`，战斗数值与反馈矩阵的唯一数据源）。
`tests/combat_rules_test.gd` 会读取本页的 `rules` 代码块和两张表，与 `CombatRules` 逐项比对：改数值必须连这页一起改，否则测试失败。

## 1. 挥砍帧表

下标 = 连段步；第三刀是终结击。判定期同时是弹反窗口（弹反不是独立按键）。

| 段 | 前摇 s | 判定 s | 后摇 s | 伤害 | 出手分量 |
| --- | --- | --- | --- | --- | --- |
| 1 | 0.18 | 0.12 | 0.26 | 1 | light |
| 2 | 0.14 | 0.12 | 0.20 | 1 | light |
| 3（终结） | 0.30 | 0.17 | 0.46 | 2 | finisher |

- 空闲冷却 0.40 s，从后摇开始计时；连段按键不受它限制，只有从空闲重新起手才等它。
- 预输入：空闲冷却期内的按键最多缓冲 0.16 s；前两刀判定期最后 0.12 s 和整个后摇可预输入下一刀；队列最多一刀，第三刀封顶，按住不自动连击。
- 补接：后摇刚结束后的 0.10 s 内按下，仍算接上一刀（不被空闲冷却吃掉）。
- 任意挥砍阶段水平速度倍率 0.42，并带提交锁（加速度 x0.35、目标速度 x0.45）。判定期起点有 78 px/s 的前冲。
- 毒素档位叠加：温档起每刀 +1 伤害（见 §4）；炽档起终结击击退 x1.35。

## 2. 取消规则

后摇进度 0 = 后摇刚开始，1 = 后摇结束。

| 动作 | 前摇 | 判定期 | 后摇 | 空闲 |
| --- | --- | --- | --- | --- |
| 冲刺 | 不可 | 不可 | 挥空：进度 >= 0.60；打实（命中或弹反）：从后摇开头 | 随时 |
| 跳跃 | 起跳照常（挥砍不被打断） | 起跳照常（挥砍不被打断） | 挥空：进度 >= 0.60 起跳同时收掉后摇；打实（命中或弹反）：从后摇开头 | 随时 |
| 再次攻击 | 不可 | 最后 0.12 s 可预输入 | 可预输入（第三刀不可） | 冷却结束 |

- 前摇与判定期没有任何取消：预输入只排队，**从不缩短已承诺的阶段**。
- 冲刺预输入 0.12 s：按早了的冲刺（取消窗口还没开、冷却中）最多等 0.12 s，窗口一开立刻出；过期即丢。
- 判定期内已经按下跳跃、人已离地时，这刀打实（命中或弹反）会在**后摇第一帧**收刀；跳跃本身仍不缩短前摇 / 判定期。挥空则保持完整后摇（沉重承诺不变）。
- 冲刺 / 跳跃收刀后，冷却走完之前按下攻击仍算接刀：收刀时记住这一按，冷却一归零立刻起第一刀（不自动出刀）；收刀本身把连段归零。
- 事件线程会记下按键（有效 6 个物理帧），顿帧 / 慢动作里物理帧很稀时，按下又松开的短按不会被轮询看漏（攻击、跳跃、冲刺同理）。暂停、过场、死亡清空全部预输入。
- 跳跃缓冲 0.14 s、土狼时间 0.12 s；冲刺期间跳跃缓冲冻结，冲刺结束那一帧立刻起跳。

## 3. 资源规则

| 项 | 规则 |
| --- | --- |
| 攻击消耗 | 无（只有时间成本：前摇 + 后摇 + 冷却） |
| 冲刺消耗 | 无（时间成本：冷却 0.42 s；空中冲刺每次落地刷新 1 次） |
| 冲刺 | 0.13 s，无敌帧 0.13 s（与冲刺等长），速度 236（温档起 x1.12） |
| 受击无敌 | 0.45 s |
| 毒素获得 | 毒池 36/s，锈雨 8/次（`ToxinPool` / `WorldClock`）；不进毒池 8/s 自然流失 |
| 毒素花费 | 弹反成功净化 12%；净化祠 / 滤芯洗掉全部；满溢每 0.55 s 掉 1 点生命 |
| 弹反返还 | 毒素 -12%、共鸣 2.0 s（钩索冷却减半、余烬步可再跳、双槽冲击波点亮）、一次空中跳、慢动作 0.12 s |
| 破绽 | 被弹回的弹丸命中敌人后 1.2 s 内，剑的下一击伤害 x2（只吃一次；非盾类敌人同时硬直 0.55 s） |

### 钩索拽人（战斗用法）

- 没有锚点可钩时，面朝方向 180 px 锥内可拽的小型敌人（骸骨、幽魂、火骷髅、飞行恶魔）被拽到骑士面前 26 px；重甲 / 首领不吃。
- 空中目标压到剑的判定期高度（玩家脚点上方 14 px），地面目标保持原脚点：拽到面前就真的落在剑的 22x16 判定范围内。
- 出索只有出索声；命中音 / 火花 / 圆环在 0.22 s 到达的那一拍才落下，与敌人 0.55 s 硬直、头顶青色破绽菱形同一帧。绳索跟着目标实时收短。
- 朝向读 `PlayerController.facing`，转身同帧按钩索也朝新方向出索；共鸣窗口里冷却减半。
- 双槽（窑匠 + 余烬步）+ 共鸣的终结击冲击波判定 56x22，画面上的外框冲击波与判定同尺寸；命中反馈走 heavy 行。

- 出手分量：攻击者 `Hitbox.blow` 为底；单次伤害 >= 2 把 light 抬到 heavy；致命一击一律 finisher。
- 材质由敌人的 `hit_material` 声明（骷髅 / 火骷髅 = bone，齿轮盾卫 = armour，刽子手 / 梦魇 = boss，幽魂 = ghost，其余 flesh）；盾面挡下一击走 shield 行（`Juice.block_feel`，弹反把盾击碎用最重的 shield_break）。
- 骑士受击：顿帧 60 ms（缩放 0.08）、震屏 4.0 px / 160 ms、屏幕红闪 alpha 0.34 / 90 ms；骑士精灵自身的受击红闪也钉在 90 ms（`Player.HIT_FLASH_SECONDS`），不会比屏幕闪多红一截。弹反：慢动作 120 ms（0.25）、闪色 alpha 0.34 / 140 ms、震屏 3.0 px。
- 判定期第一帧已经与剑重叠的敌人 / 弹丸在**同一帧**结算：贴脸挥砍不再晚一个物理帧，贴脸弹反也不再等 Area2D 的下一次刷新。剑先于火带 / 冲击波拿第一击，破绽翻倍不会被副伤害抢走。
- 被弹反 / 破绽的青色菱形向右偏 6 px，与金色破绽箭头并排：盾卫同时露出硬直和翻倍窗口时，两个符号都读得出来。
- 音效键里还没入库的新键自动退回老键（`CombatRules.SFX_FALLBACK`），音频包补库后原样生效。
- 震屏、闪屏在落手那一刻读 `Settings.shake_scale` / `Settings.flash_scale`（从不缓存）；闪屏透明度另有上限 0.40（骑士死亡的压暗除外），震屏上限 6.5 px，保证特效不盖住骑士剪影、敌人前摇、台缘和地面危险物。

## 6. 读招表

每种敌人一个独有的前摇暗号；判定出现前至少 0.25 s（`TELEGRAPH_MIN`）；出招后有一段看得见的破绽（头顶金色箭头 / 眩晕 / 放下盾）。

| 敌人 | 读招 s | 破绽 s | 暗号类别 | 暗号 |
| --- | --- | --- | --- | --- |
| spitter | 0.45 | 0.35 | pulse | toxic_swell |
| scrapper | 0.45 | 0.50 | pose | paw_crouch |
| skeleton | 0.32 | 0.45 | pose | bone_lean |
| ghost | 0.28 | 0.35 | ring | wail_ring |
| fire_skull | 0.30 | 0.30 | pulse | flare_swell |
| flying_demon | 0.55 | 1.00 | pulse | crimson_flap |
| gear_shield | 0.50 | 1.50 | pulse | arm_raise |
| executioner | 0.52 | 0.65 | zone | axe_zone |
| nightmare | 0.70 | 1.10 | lane | lane_lock |

- 喷吐者：炮口与身体涨成毒橙 0.45 s，吐完冒烟 0.35 s 是破绽。
- 碎甲者：蹲身 + 琥珀色 0.45 s；撞墙 / 坑口眩晕 0.95 s，冲满一程落空也眩晕 0.5 s。
- 骸骨：贴身后不是一碰就伤，先后仰 + 骨白闪光 0.32 s，骑士退开这一口就落空；咬完张嘴 0.45 s。
- 幽魂：青色圆环收向身体 0.28 s，收满才出判定；出手后僵 0.35 s。
- 火骷髅：悬停涨亮 0.30 s 才扑；扑完停一拍熄暗 0.30 s 再拉开。
- 飞行恶魔：猩红染色 + 膨胀 0.55 s 才俯冲；俯冲结束悬停 1.0 s。
- 齿轮盾卫：抬手蓄力 0.5 s（余烬色）才射；正面硬砍无效，反弹其弹击碎盾 1.5 s 硬直。
- 刽子手：余烬脉冲 + 地面落点红框 0.52 s（框与判定盒同位同尺寸），判定 0.16 s，收斧 0.65 s 无盾。
- 梦魇：蓄势微红 + 地面路径线 0.7 s，最后 0.2 s 锁向（线变白实线），冲锋后喘息 1.1 s。
- 本表的 time / punish 与敌人脚本的实际常量逐项交叉校验（`combat_rules_test.test_telegraph_table_matches_enemy_behaviour_constants`）。cue 只说明暗号的形状类别；九种暗号的颜色与 signature 互不重复（`enemy_readability_test` 另查唯一性），同一个 pulse 家族也靠颜色、体型变化和音效区分，不会读成同一招。

## 7. 首领

- **刽子手**（13 HP，二阶段 <= 6 HP）：一阶段斩（冷却 2.1 s）与单发射弹（2.0 s 一发）；二阶段斩冷却 1.6 s、每发射弹附带一发瞄准弹、间隔 1.15 s，斩后紧跟一发（0.55 s），相变后先吼叫 0.6 s 举盾站定再开新招，斧上持续冒余烬。
- **梦魇**（16 HP，二阶段 <= 8 HP）：一阶段「蓄势 0.7 s → 冲锋 → 喘息 1.1 s」；二阶段前摇 0.58 s、喘息 0.9 s、冲速 x1.12，相变后第一手固定是嘶鸣，之后每第三手嘶鸣召火骷髅（上限 4 只），锁向仍留最后 0.2 s。
- 相变：`GameEvents.boss_phase_changed(boss_name, 2)` + 短慢动作（200 ms / 0.2）+ 震屏 4 px + 圆环 + 闪色（alpha 0.30，受 `flash_scale` 缩放）+ 吼叫音效。
- 开场：骑士被首领发现、开场开始的那一刻先发 `boss_intro_started(boss_name)`，紧接着发 `boss_appeared`。
- 死亡：`Juice.boss_death_beat`（慢动作 700 ms / 0.18、震屏 6 px / 500 ms、双圈、碎屑、音效）+ `GameEvents.boss_defeated`。
