# P7 系统选项与验收

设置独立写入 `user://settings.cfg`，不加入战役存档格式。删战役档不会重置设置；辅助选项全部以 100% 为默认值。

| 选项 | 范围 | 生效边界 |
| --- | --- | --- |
| 受伤倍率 | 50–150% | 仅玩家的输入伤害，按整数生命四舍五入，最低 1；随后应用装备减伤，敌人生命与伤害数据不变 |
| 弹反窗口 | 100–150% | 100% 只在原判定期弹反；150% 额外覆盖后半段前摇。辅助前摇只查询投射物，不提前开启剑的伤害判定；空闲和后摇不弹反 |
| 毒素速率 | 50–150% | 仅玩家的正向暴露；净化与负向变化不缩放 |
| 字幕速度 | 60–150% | Caption 的逐字显示速度，正文与停留时长不变 |
| 文本缩放 | 85–135% | 从主题原始字号缩放，保留标题/正文/小字比例；已打开的主题同步更新。设置页可滚动并跟随焦点 |

战斗入口集中在 `CombatRules.incoming_damage`、`parry_windup_start`、`toxin_exposure`；不要在章节脚本中重复乘倍率。

显示默认保留原有整数像素模式。等比自适应使用分数缩放显示完整 16:9 画面；扩展视野按窗口比例增大真实世界 SubViewport，UI 保留居中的 1280×720 安全设计区；整数模式按 640×360 世界像素做整数倍缩放并居中留边。三种策略由同一个 `PresentationMetrics` 数据源驱动，窗口 UI 和世界鼠标坐标沿同一条变换。

设置页提供九档窗口分辨率和垂直同步。窗口分辨率、全屏、缩放策略和垂直同步均持久化；启动时恢复一次窗口模式，之后不会在换章时反复切屏。

地图使用独立的 `map` 动作（默认 M / 手柄 Back，可重绑）。游戏中直接打开会暂停，关闭直接返回游戏；从暂停菜单打开则返回暂停菜单。过场和换场期间不会从热键打开地图。

暂停与返回共用 `ui_cancel`（Esc / 手柄 Start），两者保留给菜单、不可重绑。Start 可打开和关闭暂停菜单，也可从设置、教程、操作说明及地图子页返回暂停菜单；B 保留给技能 1。`gamepad_input_test` 验证真实按键的 InputMap 映射和保留规则，`pause_menu_test` 通过 `Input.parse_input_event` 注入真实 Start 事件验证完整暂停 / 恢复及子页返回。

战役死亡等待可按确认键结束，复用同一个等待信号，连续确认不会重复安排复活。新关 HUD 在复活后提示“余烬巢已复位 · 生命与毒素已恢复”。试炼与竞技场死亡由各自模式处理。

通关后的“回看余烬”打开总结层，包含结局正文、14 章完成刻度、试炼成绩、竞技场记录和指定 Boss 复战。复战复用 TrialRun 的固定装载、重试、独立记录与战役写锁；选中一位只载入一场真实 Boss。当前 Boss 的死亡旗标在 `has_flag` 查询中临时屏蔽，底层战役旗标保留，退出后恢复正常读取。复战落点从当前章节的竞技场常量推导，不再使用旧章节坐标。

`tools/gen_audio_sfx.py --only hazard_ --no-beds` 生成 14 个机关提示/判定音效（约 1.10 MiB），`--only bed_title --no-sounds` 生成 24 秒炉厅环境循环（约 219 KiB）。HazardFx 自动解析专用键；同一机关音效最多 2 声部，最短启动间隔 0.18 秒。标题床走 Ambience 总线，离开标题会撤销目标增益。数值审计使用 `tools/gen_audio_verify.py --only hazard_` 和 `--only bed_title`，只证明解码、峰值、直流偏移和循环接缝，不代表人耳混音评审。

`tests/system_budget_test.gd` 限制每章最多 32 个机关、64 个 Light2D、6000 个世界节点，并验证专用音效路径与声部上限；标题已有独立的 8 灯/250 节点守卫。这些是节点预算，不能替代真实设备帧耗测量。

可复现的 UI 渲染入口是 `tools/systems_acceptance.tscn`。它在离屏 Windows OpenGL 窗口生成 1280×720 与 1920×1080 的辅助页、135% 字体、显示页与总结页，共 8 张截图，输出到 `screenshots/acceptance/overhaul-v3/systems/`。其中章节与成绩使用隔离的展示夹具，不是通关证据。截图已检查默认与大字体布局；手柄实机手感、实体屏幕同步和音频主观品质仍需真人验证。
