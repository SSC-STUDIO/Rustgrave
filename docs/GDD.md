## 2. Story Premise（故事前提）

世界本身是一座**巨型地下陵墓**：一座机械文明在炉心熄灭后，把整座城市沉入岩层，用铁与石为自己修了棺材。如今一切都在氧化。梁柱是锈红的，空气里是致癌的铁尘，远处永远有坏掉的引擎在回声里空转。

文明自称 **炉约（the Cinder Compact）**。他们相信只要中央熔炉不停，灵魂就能在金属里循环。炉灭之后，循环变成了锈：记忆凝成硬块，仇与誓变成会走动的废铁。橙色泥浆是失败的冷却剂，被后世叫作 **腐液（Sludge）**——它吃肺，也吃记忆。

玩家是 **余烬骑士**：一堆废料里偶然复燃的微小灵体，被绑在一柄与自己不成比例的锯齿巨剑上。你不是被选中的英雄，你是炉约最后的**失败净化偶**——本来该把锈从世界里刮掉，结果自己先锈透了，又被某一次余烬回流点亮。剑是一口棺材。插座里的锈核是死人的职称，不是经验。

已落地的战役是**十章直线**：腐液回廊、沉钟地窟、锈城街巷、圣殿中庭、齿轮工坊、墓园夜雨、钟楼、熔渣深渊、锈城城墙、炉心深处。每章只推进一个事实。全文见 `docs/story.md`。早期草案里的五区轮毂没有铺成地图。

叙事钩子：

1. **表面目标**：穿过十章，抵达炉心深处。
2. **第一章残芯**：熄灭，则骑士与残芯同散（提前结局，写入 `snuff`）。复燃不是拯救，是答应把剑里的人带到炉心再问一次；这一次不写入结局。
3. **第十章炉心之门**（梦魇死后）：送剑，声音回到火里，火稳下来，骑士散成铁，陵墓睡下（`give`）。守火，炉心继续不规则地跳，骑士留下当看守，声音还在剑里（`keep`）。两条都点亮 `game_complete`。

语调：压抑、哀悼、偶尔黑色幽默（路牌还写着“请勿在齿轮上用餐”）。不写高昂拯救世界演讲。

## 3. 玩家幻想与角色

余烬骑士很小，剑很大。幻想不是“我很强”，而是：

- **我很沉。** 每一步、每一跳、每一刀都有重量。承诺动作，而不是取消连招。
- **我很准。** 巨剑既能砸开压力板，也能在弹丸贴面的那一帧把它打回去。
- **我在拼自己。** 成长不是升级数字，是往剑的插座里嵌进锈核，改变这把剑能做什么。

视觉：破披风、补丁盔、锯齿巨剑。剪影必须在 64×64 里可读。见 `docs/art-spec.md`。

## 4. Core Loop（核心循环）

单次有效游玩循环：

1. **进入** 一个未知房间（来自炉毂或相邻生态区）。
2. **观察** 地形重量：腐液、垂直落差、会射弹的敌人、看起来像门锁的压力板。
3. **战斗 / 穿越**  
   - 用带前摇后摇的重斩清近身；  
   - 用挥砍判定帧把弹丸 **弹反** 回去；  
   - 用冲刺 i-frame 穿过伤害窗；  
   - 用重量踩下压力板，打开门或桥。
4. **收获** 锈核、滤芯齿轮、捷径、地图知识。
5. **回炉** 在剑的插座里插入核心 → 新能力改变可到达范围。
6. **回溯** 旧区：熔掉锈门、钩过断层、踩到以前踩不动的结构。
7. **净化** 在稀有净化祠洗掉毒素，再进入下一层更毒的区。

失败循环：毒素满溢受伤、笨重挥空被惩罚、弹反失败吃弹。复活点设在炉毂与少数生态区余烬巢（后期设计），脚手架阶段为测试房重生。

## 5. 核心机制

### 5.1 Weight & Momentum（重量与动量）

- 地面移动用 **可变加速度**：起步慢、刹停慢，转身需要克服惯性。不是“轻快平台跳跃”。
- 跳跃：起跳干脆，**下落重力放大**，空中短暂二段跳（可被能力锁）。
- 冲刺：短距离、带 **无敌帧**，用于穿过弹幕与毒素边缘，不是无限位移。
- 巨剑：每次挥砍有 **前摇（wind-up）** 与 **后摇（recovery）**。连点无连斩。战斗是节奏与站位，不是按钮雨。

设计目的：让“重”成为可读规则——重所以能压板；重所以挥空会被惩罚；重所以弹反成功时快感更大。

### 5.2 战斗：斩击即弹反

巨剑有两种合法用途：

1. **杀** —— 近战 hitbox，冷却明确。
2. **弹** —— **在挥砍的判定帧内** 剑刃与敌方投射物重叠，则将弹丸 **改写归属并折返** 向来源 / 敌人。

弹反不是独立“格挡键”的主方案（可保留同键别名）。技能表达是：**时机藏在攻击里**。挥早了弹丸尚在飞行，挥晚了已经吃弹。这与 Weight & Momentum 一致：你必须为这一刀付出后摇，所以选择“现在斩”还是“等弹”是核心决策。

### 5.3 Rust-Core 插座（锈核）

敌人掉落锈核。玩家不“升级”，而是把核心 **插入剑上的插座**。

- 初期 2 个插座（刃根 Guard、刃腹 Fuller）。后期可在锻炉解锁刃尖 Edge、剑柄 Pommel。
- 同一时间，插座里的核心决定 **当前能力负载**。可卸下换装，但不能无代价（卸核需要插座台或炉毂，防止战斗中乱切）。
- 能力示例（见第 6 节）：**钩锁系绳（Hookshot Tether）**、**熔热锻（Heat Forge）**。

### 5.4 Toxin Meter（毒素槽）— 已落地为「腐液即燃料」

- 接触橙色腐液持续积毒。槽满后开始 **持续掉血**，档位加成不撤。
- **档位**：0–29 冷（无加成）/ 30–59 温（伤+1、钩程+20%、冲刺+12%）/ 60–99 炽（终结击退、熔热锻短火带）/ 100 满溢。
- **弹反精炼**：判定帧弹反成功 `purify(12%)` 并点燃 2 秒共鸣（钩索冷却减半、余烬步可再跳）。
- **净化祠 / 滤芯**：战术选择——洗掉力量换活命，不是纯奖励。

### 5.5 交互物

统一接口：可交互物实现 `interact()`（Godot 中以基类约定代替 C# 接口）。

- **压力板**：骑士的重量（及未来的剑砸）可触发，用于开门、抬桥、启动老升降机。
- **门**：被板、锈核能力或机关打开。
- **废料堆**：可搜刮，常藏锈核或滤芯。

## 6. Ability Progression Tree（能力进阶树）

成长轴 = **探索门闸**，不是 DPS 数值膨胀。每个能力必须同时是：新的战斗动词 + 新的空间许可。

### 6.1 插座布局

```
        [Edge] 后期：刃尖
           |
Pommel —— 剑 —— Guard（初始）
           |
        [Fuller] 初始
```

| 插座 | 主题 | 典型核心 |
| --- | --- | --- |
| Guard（护手） | 生存 / 位移防御 | 滤毒、短 i-frame 强化 |
| Fuller（血槽） | 空间移动 | Hookshot Tether、二段跳余烬步 |
| Edge（刃尖） | 环境破坏 | Heat Forge、破盾重斩 |
| Pommel（柄锤） | 重量机关 | 砸地冲击波、远距压板 |

落地：2 插座；插入即解锁。余烬步默认锁死，须镶 Ember Core。双槽组合：熔钩 / 爆燃斩 / 摆荡步。

### 6.2 主干能力树

```
余烬苏醒（默认）
 ├─ 重斩 / 弹反窗口
 ├─ 沉重走跳
 ├─ 冲刺 i-frame
 └─ 重量压板
      │
      ├─ Fuller：余烬步（Ember Step）— 额外跳跃门闸
      ├─ Fuller：钩锁系绳（Hookshot Tether）— 钩住齿轮锚点跨越断层
      ├─ Edge：熔热锻（Heat Forge）— 融化锈门 / 点燃油带
      ├─ Guard：滤毒隔膜 — 毒素积蓄减缓
      └─ Pommel：柄锤震击 — 远程触发压力板
           │
           ├─ 进阶：回钩弹射（钩锁 + 弹反：把钩头当弹丸打出）
           ├─ 进阶：熔渣斩（熔热锻 + 重斩：短暂火刃）
           └─ 终局：炉心嵌合（仅深渊锻炉）
```

### 6.3 关键能力设计备注

**Hookshot Tether**  
- 战斗：短前摇射出钩头，命中敌人可拉近或把轻型敌人拽过来（与“你很重”一致：你不太被拉走，是世界被你拽）。  
- 探索：钩住场景锚点（齿轮、梁钩）越过不可跳断层。  
- 已落地：钩住锚点匀速拉近，跳跃/撞墙脱钩。

**Heat Forge**  
- 战斗：短时间让斩击附带熔渣，对“锈壳”护甲有效。  
- 探索：融化标记为锈封的门与栅。  
- 脚手架：测试关锈门在已镶嵌该核时可交互融化。

能力永远不做成纯数值被动（+5% 伤害）。若一个核没有改变地图可达性，它不该占据插座。

## 7. Enemy Design Philosophy（敌人设计哲学）

敌人是 **关卡句子**，不是血包。每一类敌人只教 1 个主规则，再在后续生态区做变体。

### 7.1 原则

1. **可读承诺**：敌方出手有风声、有发光、有停顿。玩家的重斩也很慢，所以敌人必须同样遵守“先说话再打”。
2. **弹丸是对话**：只要会射，就应能被弹反（除非 Boss 明确声明“熔核不可弹”）。弹反是对玩家技术的奖励，不是彩蛋。
3. **重量差**：轻型废铁可被弹丸与斩击打退；重型碾压机无视击退，必须用板、钩、熔门来处理，而不是堆 DPS。
4. **生态区变体优于新怪数量**：同一“喷吐者”在下水道变为毒泡、在窑炉变为熔渣、在深渊变为回声弹。
5. **死亡有残响**：掉锈核，不掉经验条。精英掉带名字的核（某个炉匠的职称）。

### 7.2 原型谱系

| 原型 | 教什么 | 反制 |
| --- | --- | --- |
| 喷吐者 / 炮台 | 弹反时机 | 在判定帧挥砍 |
| 巡逻锈兵 | 重斩距离与后摇 | 等刀、惩罚挥空 |
| 腐液寄居蟹 | 毒素空间 | 绕路、滤芯、冲刺穿边 |
| 齿轮盾卫 | 正面无法硬砍 | 弹反其弹、绕背、熔热锻 |
| 空中钩蝇 | 垂直骚扰 | 二段跳 / 钩锁 |
| 碾压躯体（小型 Boss） | 你不能用普通斩击解决重量 | 压力板、落砧、环境杀 |

测试关只放 **喷吐者（Spitter）**，专门练习弹反。

### 7.3 不要做的事

- 不要无预警的全屏伤害。
- 不要海量杂兵消耗玩家的后摇——一次遭遇 1–3 个句子。
- 不要把毒素和弹幕同时开到无法阅读。两者都是压力，需错开峰值。

## 8. Level Verticality Notes（关卡垂直性）

已落地的地图是**十章直线里的陵墓剖面**。章与章顺序固定。一章内部仍用高度做记忆：看得见的钩点、吊台和坑，先看见，能力够了再过去。主线不把钩锁和二段跳当成必经门闸。

### 8.1 总则

- 章内可以有一条看得见、要钩或要跳才好走的捷径；主路仍然能走完。
- 下落永远比上升便宜：下落是风险（腐液、尖齿），上升是能力税。
- 镜头允许竖直房间，但战斗房高度应让弹道可读（测试关已用 640×360 视口验证水平 look-ahead）。
- 压力板常放在下层，门开在上层或对侧——用重量把“我在下面”变成“上面的路开了”。

### 8.2 分章垂直语言

**壹 · 腐液回廊**  
塌陷的水平层。教走、跳、冲、压板。掉下去是浅坑和第一滩腐液。

**贰 · 沉钟地窟**  
整体向下。苔水在底，吊台横跨。钟在数人。

**叁 · 锈城街巷**  
横向街面，塔和阶在视线里。窗里的光是锈苔。

**肆 · 圣殿中庭**  
中庭有落差。吊灯还亮着，签过名的手已经不在。

**伍 · 齿轮工坊**  
吊链和升降。插座在这里切开。

**陆 · 墓园夜雨**  
土丘垫高，树冠上有钩点。哈伦和薇尔埋在这里。

**柒 · 钟楼**  
这一章的竖井。吊台往上，钟舌已经不在。

**捌 · 熔渣深渊**  
热坑。先看见渣，再踩过去。净化偶是在这里淬火失败的。

**玖 · 锈城城墙**  
横向城墙。风从炉心来，墙把风关在里面。

**拾 · 炉心深处**  
熔渣河之后是平地竞技场。终局不在“打一个更大的怪”，在门后的选择：把剑送进炉心，或留下看守。

### 8.3 测试竞技场如何对应

`TestArena` 是垂直语法的缩写：左高台练跳与冲，中坑是腐液，右高台是弹反靶，压力板→门→废料堆→插座台→锈门。正式战役是上面的十章，见 `docs/story.md`。

## 9. 地图结构

```
腐液回廊 → 沉钟地窟 → 锈城街巷 → 圣殿中庭 → 齿轮工坊
```

顺序固定。章内的钩锁、余烬步和锈门是捷径或支路，主路用走、跳、冲、压板和热锻就能通过。

| 叁 锈城街巷 | 人自己走下去；窗是锈苔 | 街面 |
| 肆 圣殿中庭 | 灯还在，手成灰 | 中庭落差 |
| 伍 齿轮工坊 | 插座在此切开；核是职称 | 吊链 |

## 10. 战斗节奏与数值方向（设计，非最终）

- 玩家生命：少（约 5 格），受击有短暂无敌，但后摇中被打会感到“这是我的错”。
- 一次标准斩：前摇约 0.18s，判定约 0.12s（弹反窗口），后摇约 0.25s。
- 弹丸飞行速度必须让窗口可练：太快则不公平，太慢则不像威胁。
- 冲刺 i-frame ≈ 冲刺时长，冷却明显，防止无限无敌。

## 11. UI / UX

- 毒素槽：橙色，放在生命下方，满槽脉动。
- 锈核：剑形简图 + 插座孔；未镶为空洞，已镶为核色。
- 交互提示：靠近时显示 `E`。
- 弹反成功：短闪与 HUD 提示（音效用高频 clink，见 `docs/audio-mood.md`）。
- 地图（后期）：手绘风陵墓剖面，不显示未到达房间的内部。

脚手架 HUD 为像素风色块，功能完整。

## 13. 美术基调

见 `docs/visual-prompt.md` 与 `docs/art-spec.md`。主色：Shadow `#3A3A3A`、Rust Dark `#8B4513`、Rust Light `#CD5C5C`、Toxic Glow `#FF8C00`、Teal `#4A6B6B`。16 色上限，无抗锯齿，破披风。

陵墓昼夜约 20 分钟一轮（昼→夜约 10 分钟），开局在黄昏。白天略压暗，夜里是冷色暗廊（约三到四成亮度），点燃的余烬巢立刻划出暖池和光晕，不靠全屏滤镜。天气为薄雾 / 雨 / 锈雨 / 浓雾（偶发余烬风）。室外常驻微风：树丛绕根轻摆，雨/雾/尘跟同一风向走；阵风一阵一阵，室内风停。锈雨只在室外缓慢叠一点毒素（远低于毒池），不改跳跃、不吹玩家。室内（锻炉残室）有炉口暖池，雨停在门外。点燃的余烬巢在夜里划出暖池和淡光柱，会被实心平台挡住；未点燃无火无光。月只做很弱的冷填。过场收宽银幕。
