形状评价：东西向长廊，"毒池 + 三块踏石"做了两遍，Boss 场是平地。
测试：`tests/level02_layout_test.gd`、`level02_scene_test.gd`、`hollow_bell_test.gd`、`chapter_progression_test.gd`、`route_audit_test.gd`。

**结构决定（你来选，写进蓝图）**：要么把 `Level02Layout` 迁成 `ChapterLayout` 子类（登记 `GameContext.LAYOUTS`，场景根脚本改 `ChapterLevel` +
`layout_path`，更新 `level_routing_test` 里"level01/02 不在 LAYOUTS"的断言与 level02 相关测试，保持 `level02:` 命名空间与存档路径），
这样助手 / 体检 / 路由审计统一适用——**优先选这个**，只要迁移风险可控；要么保留旧结构、直接 `CyclicHazard.new()` 等实例化机关节点。

新设计：**螺旋下探**（沿竖井一圈圈下到钟门，而不是一条东西向长廊；至少两个明显高度层）+ **坠钟**（`cyclic(..., "bell")`，地上阴影预警，
第一处放在安全处教学）；用坠钟节奏取代第二组"毒池 + 三块踏石"。Boss「空钟」竞技场做成**笼状**：钟笼栏杆 / 抬高台 / 两侧龛位

可选挑战：锈门后的壁龛（已有钩锁支路可保留）加一个奖励位。

## level02b 运渣水渠（theme undercroft，渣水）

现状：`scripts/levels/chapters/level02b_layout.gd`，宽 3680、camera_top -112；3 段地面 + 2 个宽坑（x≈560–720、1120–2064）、7 级踏台、3 台吊台；
巢 176 / 1060 / 2890（最大间距 1830，偏大）；敌人：碎铁犬 3、喷吐者 1、幽魂 1、飞魔 1；压板门；钩锁 → `toxic_ward`；
绞盘守渠人（Capstan Warden）场 x≈2940–3540；渣水有 sludge ramp。形状评价：把 level02 的"坑 + 踏石"放大了一倍。
测试：`tests/level02b_layout_test.gd`、`capstan_warden_test.gd`。

新设计：**双水位切换改变路线**（压板 / 绞盘开关让水位升降：低水位露出下层渠底通道，高水位浮起上层吊桥；两个状态各有一条路，
主线两种都能走，各有风险）+ **闸口涌流**（`force_zone(..., "water", push)` 阵风式涌流，`gust_period` 4–6s，把人冲向下游；`gust` 前 0.6s 有预兆）。
绞盘守渠人竞技场：加"排水"机制（竞技场里水位随 Boss 阶段下降，露出新的立足点）——只改场地，不改 Boss 数值。
巢距调到约 1000px，补一条单向捷径与一个带奖励的可选挑战。
