## 新设计

- **走廊 → 环形大殿**：前半走廊加一段下探 / 回环（让玩家进殿前先看到殿的轮廓），大殿本身是**环形**：外圈走道 + 中央炉台 + 四个立柱掩体，
  不再是 1200px 平地；Boss 场边界仍由 `arena_left/right` 约束（梦魇受边界夹持，`tests/nightmare_boss_test.gd` 锁着尺寸与攻击表，不改）。
- **炉心脉冲**（`cyclic(..., "shock", {"thick": 260~300})`，贴地冲击波，**跳起或站上立柱台能躲**）：在竞技场里作为场地机关，
  与梦魇的阶段同步——一阶段只有一个慢脉冲，二阶段 / 三期（余烬雨 / 地裂 / 热浪，见 `nightmare_boss.gd`）加快并错相；用
  `GameEvents.boss_phase_changed` 驱动改 `rest_time`（保证"休止 + 预警"≥1.2s 的体检底线），不要改 Boss 本身。
- 渣渠过渡用节奏机关（`cyclic(..., "slag")`）而不是更多踏石，但保持主线只需单跳 / 冲刺 / 热锻；
- 补一个竞技场前的巢（间距约 1000px，Boss 前存档点距门 ≤80px，且在火骷髅 / 幽魂的仇恨圈外）、一条单向捷径、一个带奖励的可选挑战
  （守夜台钩锁支路保留并加奖励位）。
- 敌人变体：火骷髅低空廊保留，`heavy_guard` 不在本章（盾卫不在原敌人表里，别新增）；可用 `alert_radius` 让火骷髅成群。
