`class_name CandleBridge`，继承 `SolidPlatform` 或同等写法，进 `hazards` 组并带 `hazard_kind="candle"` 元数据）：
- 台阶平时无碰撞、半透明剪影；骑士靠近一座**点燃的烛台**（烛台是 `Area2D`，骑士进入半径 ~48px 或斩击烛台时点燃）后，
  它关联的桥面在 `lit_time`（约 6s）内实心，烛灭台灭，再靠近重新点燃；桥面消失时脚下没有致命后果（落到下层石台，不死、不软锁，
  且下层有路回来）；
- 提供 `ChapterLayout` 助手 `candle_bridge(host, name, pos, width, candle_pos, props)`（向后兼容地加在 `chapter_layout.gd` 的机关区，并汇报）；

  首遇提示键 `&"candle"` 已在 `HintService.CATALOG`；
- 测试 `tests/candle_bridge_test.gd`（点燃 / 熄灭时间线、碰撞开关、靠近点燃、体检规则）。
唱诗班竞技场要有地形（抬高台 / 烛台掩体 / 侧龛），不改 Boss 本体。加敌人变体（`exploder_skeleton` 守窄道，注意死后爆裂要留退路）。
巢距约 1000px；补一条单向捷径与一个带奖励的可选挑战。

## level05 齿轮工坊（室内有顶，theme industrial，吊台与压板最多的一关）

现状：`level05_layout.gd`，宽 4000、camera_top -48；7 段地面、4 个冷却池坑、5 台吊台、3 个齿轮石、上层检修步道（y=208）；
巢 176 / 1616 / 2576 / 3408（最大 1440）；敌人：碎铁犬 3、喷吐者 2、幽魂 2、飞魔 1、盾卫 1；2 套压板门、锈门、3 个钩点、余烬核在主线（走道 E 台阶）。
形状评价：吊台最多，但脊梁仍是 y=320。测试：`tests/level05_layout_test.gd`（吊台上下船、冷却池坑底净空 `test_quench_pit_has_headroom...`、
压板 / 锈门 / 检查点——保留这些"困路"断言的精神）。

新设计：**三层机械迷宫**（地面机房 / 中层检修步道 / 顶层吊轨，三层之间由吊台与压板连接，主线可走中层或地面）+
**传送带**（`conveyor()`，正向加速、逆向费劲，带 `flip_period` 反向前先停转）+ **蒸汽喷口**（`cyclic(..., "steam")`）。
两种机关**错开使用**：传送带段不放喷口，喷口段用静止台；冷却池坑改成"传送带 + 蒸汽"过渡取代多余的踏石。
敌人变体：`armored_scrapper` 守机房口，`heavy_guard` 守压板；喷吐者别对同一段跳跃。巢距约 1000px；单向捷径 + 可选挑战奖励。
