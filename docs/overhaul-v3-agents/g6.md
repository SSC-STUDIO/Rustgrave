现状：`scripts/levels/chapters/level09_layout.gd`，宽 4200、camera_top -48；5 段地面、4 个坑、4 座塔楼叠台、14 块踏石；巢 176 / 1544 / 2536 / 3440

**风道**（`force_zone(..., "wind", Vector2(±48~72, 0), {"gust_period": 4~6, "gust_duty": 0.5})`：阵风把人推向墙外 / 墙内，
墙外是落下去的深沟，推力始终小于跑速（上限 96），冲刺不受风；落点要有"抓得住"的矮墙 / 垛口，别让一次阵风必死）。
飞魔 4 只改成 2 个分点出场；喷吐者别对同一段跳；城墙缺口用风道节奏 + 垛口过渡取代"五级风石链"。
巢距约 1000px；单向捷径（塔内吊台 / 压板直降回墙脚的巢）+ 带奖励的可选挑战（鹰巢钩锁支路保留并加奖励位）。
