`exploder_skeleton` 变体放在窄道，死后爆裂要留退路）。巢距约 1000px（现在最大 1328，补巢）；单向捷径 + 带奖励的可选挑战

## level07 钟楼（竖井，theme belltower）

现状：`level07_layout.gd`，宽 1280、camera_top -1472；8 层楼板（16px 薄台）、7 台 240px 行程吊台，从 y=320 一路升到塔顶；巢 176 / 544(-160) /
1052(-640) / 1052(-1280)；敌人：骸骨 3、喷吐者 2、飞魔 2、幽魂 3；压板在井中段；顶板壁龛可选钩锁支路；**无 Boss**；出口 → level07b。
形状评价：本作唯一有强垂直身份的一关，但楼层都是"吊台接吊台"。测试：`tests/level07_layout_test.gd`；竖向机位看图用
`run_peek_live.ps1 -Level level07 -CamY -650`（以及 -300 / -1300）。

新设计：**竖井保留**（吊台节奏保留，整体高度与相机界不变，除非你同步改 `camera_top()`、顶板、室内区、背景全高覆盖）+
**侧室**（在井壁两侧各开 1–2 个侧室，进去是奖励 / 捷径 / 小遭遇，east_limit 可以从 1280 加宽到 ~1600）+
**摆锤钟舌**（`pendulum(..., {"skin": "clapper"})`：吊在井中，横跨吊台上下船的路径，摆端一侧最安全）。
摆锤别压在吊台上下船点与余烬巢上方（LevelSanity 规则）；摆锤附近 ≥48px 无判定落脚；钟楼薄台只有 16px，摆锤锚在薄台之上要避开头顶净空。
巢距约 1000px（竖向按爬升路程算）；补一条单向捷径（从塔顶落下 / 吊台直降回中层巢）与带奖励的可选挑战。
